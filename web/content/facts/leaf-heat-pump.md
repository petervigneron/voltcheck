# Nissan Leaf: Heat Pump by Model Year and Trim

## By model year and trim

Nissan's brochures for the 2018 through 2025 Leaf list a row called "Hybrid heater system" and never use the words "heat pump." Only the 2026 car's grid glosses the same row "Hybrid heater system (heat pump)."

| Model year | Trim | Feature |
|---|---|---|
| 2018 | S | Hybrid heater system — not offered[^1] |
| 2018 | SV | Hybrid heater system — SV All-Weather Package[^1] |
| 2018 | SL | Hybrid heater system — standard[^1] |
| 2019 | S, S PLUS | Hybrid heater system — not offered[^2] |
| 2019 | SV, SV PLUS | Hybrid heater system — SV/SV PLUS All-Weather Package[^2] |
| 2019 | SL, SL PLUS | Hybrid heater system — standard[^2] |
| 2020 | S, S PLUS | Hybrid heater system — not offered[^3] |
| 2020 | SV, SV PLUS | Hybrid heater system — SV/SV PLUS All-Weather Package[^3] |
| 2020 | SL PLUS | Hybrid heater system — standard[^3] |
| 2021 | S, S PLUS | Hybrid heater system — not offered[^4] |
| 2021 | SV, SV PLUS, SL PLUS | Hybrid heater system — standard[^4] |
| 2022 | S, S PLUS | Hybrid heater system — not offered[^5] |
| 2022 | SV, SV PLUS, SL PLUS | Hybrid heater system — standard[^5] |
| 2023 | S | Hybrid heater system — not offered[^6] |
| 2023 | SV PLUS | Hybrid heater system — standard[^6] |
| 2024 | S | Hybrid heater system — not offered[^7] |
| 2024 | SV PLUS | Hybrid heater system — standard[^7] |
| 2025 | S | Hybrid heater system — not offered[^8] |
| 2025 | SV PLUS | Hybrid heater system — standard[^8] |
| 2026 | S+ | Heat pump — not offered[^9]; Nissan's press release calls the heat pump standard without naming trims[^10] |
| 2026 | SV+ | Heat pump — standard[^9] |
| 2026 | Platinum+ | Heat pump — standard[^9] |

## 2026 related equipment

- Battery heater — $300 factory-installed option on SV+ and Platinum+, not offered on S+.[^9]
- The car captures waste heat from the drive motor and the on-board charger to help warm the battery.[^10]

## Scope note

US model years 2018 through 2026; the first-generation Leaf, 2011 through 2017, is not covered. For 2018 through 2025, Nissan publishes the feature as "Hybrid heater system" and does not say in any document read here what that system contains — only the 2026 grid glosses the row as a heat pump, for the 2026 car. Where Nissan's two 2026 documents differ, both are shown above.
